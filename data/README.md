# Dataset Information

## Dataset Name

Natural Language Processing with Disaster Tweets

## Source

Kaggle Competition Dataset

## Link

https://www.kaggle.com/c/nlp-getting-started

## Files Used

The following files are used in this project:

- train.csv
- test.csv
- sample_submission.csv

## Description

This dataset is used for binary text classification.

The task is to predict whether a tweet is about a real disaster or not.

- 1 = real disaster tweet
- 0 = not a real disaster tweet

The training dataset contains 7,613 labeled tweets.

The test dataset contains unlabeled tweets for final prediction.

Main columns:

- text
- keyword
- location
- target

The main input for this project is the **text** column.
